## ROS-Pakete

Im Ubuntu-/ROS-Container:

```bash
sudo apt install ros-jazzy-lanelet2*
```

Wichtig:

- `lanelet2-core`
- `lanelet2-io`
- `lanelet2-projection`
- `lanelet2-routing`
- `lanelet2-validation`
- `lanelet2-maps`
